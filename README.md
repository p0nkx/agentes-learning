# agentes-learning

Repositorio para documentar y aprender el uso de agentes de código AI, específicamente OpenCode.

Contenido:
- `index.html` - Página web con tutorial, comandos y límites de OpenCode
- Documentación generada durante el aprendizaje

## Comandos útiles

```bash
# Inicializar OpenCode en el proyecto
opencode

# Comandos dentro de OpenCode
/help          # Ver ayuda
/init           # Inicializar proyecto
/connect        # Conectar proveedor de modelos
/sessions       # Cambiar entre sesiones
/undo           # Deshacer cambios
/redo           # Rehacer cambios
```
