Todos los Comandos de OpenCode

Guia completa de comandos integrados, atajos de teclado y herramientas disponibles.

Como ejecutar comandos

Dentro de la interfaz de OpenCode (TUI), escribe / seguido del nombre del comando. Tambien puedes usar atajos de teclado con ctrl+x como tecla líder (leader key).

# Ejemplo: escribe dentro de OpenCode

/help

# O usa el atajo:

ctrl+x h (si esta configurado)

C Configuracion y Modelos

/connect ctrl+x c

Agrega un proveedor de modelos. Te permite seleccionar entre los proveedores disponibles y agregar sus API keys. Para empezar gratis, selecciona "opencode" (Zen).

/models ctrl+x m

Lista los modelos disponibles. Puedes cambiar de modelo en cualquier momento durante la sesion.

/themes ctrl+x t

Lista los temas visuales disponibles. Cambia la apariencia de la interfaz de terminal.

skill (herramienta interna)

Agent Skills - NO es un comando de usuario: Las skills no se ejecutan con /skills. Son comportamientos reutilizables definidos en archivos SKILL.md que los agentes cargan automaticamente bajo demanda.

Como ver las skills disponibles:

  • 1. En terminal, fuera de OpenCode: opencode debug skill (muestra las skills cargadas)
  • 2. Dentro de OpenCode: preguntale: "¿Qué skills tienes disponibles?" - el agente listará nombres y descripciones
  • 3. El agente carga automaticamente una skill cuando detecta que su description coincide con tu tarea

¿Se instalan por proyecto o globalmente?

  • 📁 Global (~/.config/opencode/skills/ en Linux/Mac o C:\Users\elfab\.config\opencode\skills\ en Windows): Se instalan UNA VEZ y están en TODOS tus proyectos
  • 📂 Por proyecto (.opencode/skills/ en la raiz del proyecto): Solo para ese proyecto, se pueden compartir con el equipo via Git
  • ⚡ Prioridad: Las skills de proyecto sobrescriben a las globales si tienen el mismo nombre

Dónde buscar nuevas skills:

  • • skills.sh - Directorio de colecciones de skills
  • • openagentskills.dev - Recursos y documentación
  • • GitHub: busca repositorios con archivos SKILL.md (ej. anthropics/skills)

Ejemplo: Crear .opencode/skills/git-release/SKILL.md con un name y description en el frontmatter. OpenCode lo detectará automaticamente.

S Sesiones (Espacios de trabajo)

/sessions ctrl+x l

Lista y permite cambiar entre sesiones. Cada sesion es una conversacion independiente con su propio historial, pero los cambios en archivos se reflejan en todas.

/new ctrl+x n

Crea una nueva sesion limpia. Alias: /clear. Ideal para empezar una tarea diferente sin mezclar contexto.

/resume alias

Alias de /sessions. Reanuda o cambia a una sesion existente.

/continue alias

Otro alias para /sessions. Continua una sesion previa.

E Edicion y Cambios

/init

Guia paso a paso para crear o actualizar AGENTS.md. Analiza tu proyecto y ensena a OpenCode la estructura, convenciones y patrones del codigo.

/undo ctrl+x u

Deshace el ultimo mensaje y cambios en archivos. Puedes ejecutarlo varias veces. Usa Git internamente, asi que tu proyecto debe ser un repositorio Git.

/redo ctrl+x r

Rehace un mensaje que fue deshecho con /undo. Solo disponible despues de usar undo. Los cambios de archivos tambien se restauran.

/compact ctrl+x c

Compacta la sesion actual resumiendo el contexto. Alias: /summarize. Util cuando el historial crece mucho y quieres reducir tokens.

V Visualizacion y Salida

/details

Alterna la visibilidad de los detalles de ejecucion de herramientas (tool execution details). Muestra u oculta informacion tecnica del procesamiento.

/thinking

Alterna la visibilidad de los bloques de "thinking/reasoning" en la conversacion. Solo afecta la visualizacion, no habilita/deshabilita el razonamiento del modelo. Para cambiar el razonamiento usa ctrl+t.

/export ctrl+x x

Exporta la conversacion actual a Markdown y la abre en tu editor predeterminado (configurado en la variable EDITOR).

/share

Comparte la sesion actual generando un enlace (link) que se copia al portapapeles. Permite compartir la conversacion con tu equipo. Las sesiones NO se comparten por defecto.

/unshare

Deja de compartir la sesion actual. Elimina el enlace de compartir previamente creado con /share.

? Ayuda y Salida

/help

Muestra el dialogo de ayuda con la lista de comandos y atajos disponibles dentro de OpenCode.

/exit ctrl+x q

Sale de OpenCode. Alias: /quit, /q.

/editor ctrl+x e

Abre un editor externo para redactar mensajes largos. Usa el editor definido en la variable EDITOR (ej. code --wait, vim, notepad).

> Entrada Especial (sin /)

@archivo

Referencia archivos en tus mensajes. Usa @ para hacer una busqueda difusa (fuzzy search) de archivos en el directorio actual. Ej: @src/auth.js. El contenido se agrega automaticamente a la conversacion.

!comando

Ejecuta un comando de terminal (bash). Empieza el mensaje con !. Ej: !ls -la. La salida del comando se agrega a la conversacion como resultado de herramienta.

@nombre-agente

Invoca un subagente (subagent) manualmente mencionandolo con @. Ej: @general ayudame a buscar esta funcion. Los subagentes son asistentes especializados.

Tab

Alterna entre los agentes principales (primary agents): Modo Plan (solo analiza, no hace cambios) y Modo Build (hace cambios directos). Tambien puedes ciclar con el atajo switch_agent.

A Agentes Disponibles

build primary

Agente principal por defecto. Tiene todas las herramientas habilitadas. Ideal para desarrollo donde necesitas acceso completo a operaciones de archivos y comandos del sistema.

plan primary

Agente restringido para planificacion y analisis. Por defecto, toda edicion de archivos y comandos bash requieren aprobacion (ask). No hace cambios directos, solo sugiere.

general subagent

Agente general para investigar preguntas complejas y ejecutar tareas de multiples pasos. Tiene acceso completo a herramientas (excepto todo). Invocalo con @general.

explore subagent

Agente rapido de solo lectura para explorar bases de codigo. No puede modificar archivos. Ideal para buscar archivos por patrones, buscar codigo o responder preguntas sobre el proyecto.

Tambien hay agentes del sistema ocultos: compaction (compacta contexto), title (genera titulos), summary (crea resumenes).

Limites del Plan Gratuito - Explicado

Entendiendo los limites de peticiones y tiempo de forma clara.

? Que significan los "limites de peticiones por tiempo"?

OpenCode Go (el servicio de modelos de OpenCode) funciona con un sistema de ventanas de tiempo. Cada modelo tiene un maximo de peticiones que puedes hacer dentro de una ventana de 5 horas.

Como funciona en la practica:

1

Cada vez que le envias un mensaje a OpenCode, eso cuenta como 1 peticion.

2

El contador empieza de cero y se acumula durante 5 horas.

3

Cuando pasan las 5 horas, el contador se reinicia automaticamente y puedes volver a usar tus peticiones.

4

Si llegas al limite antes de que pasen las 5 horas, tendras que esperar a que se reinicie o cambiar a otro modelo.

! Ejemplo practico

Imagina que el modelo Big Pickle (uno de los modelos gratuitos) tiene un limite de 200 peticiones cada 5 horas:

10:00 AM - Empiezas a usar OpenCode

Contador: 0 / 200

Tu ventana se reinicia a las: 3:00 PM

12:00 PM - Llevas 150 peticiones

Contador: 150 / 200

Te quedan 50 peticiones hasta las 3:00 PM

1:30 PM - Llegaste al limite!

Contador: 200 / 200 - Limite alcanzado

No puedes enviar mas mensajes con este modelo hasta las 3:00 PM. Puedes: esperar, o cambiar a otro modelo con limite disponible.

3:00 PM - La ventana se reinicio

Contador: 0 / 200 - Listo de nuevo!

Tu nueva ventana termina a las 8:00 PM.

$ Tips para optimizar tus peticiones

➤ Sere conciso: Agrupa varias preguntas en un solo mensaje en vez de enviar muchos mensajes pequenos.
➤ Usa el modo Plan: Para tareas complejas, planifica primero (no gasta recursos en cambios innecesarios).
➤ Cambia de modelo: Si te quedaste sin peticiones en un modelo, cambia a otro que tenga limite disponible.
➤ Da contexto completo: Un mensaje detallado evita tener que pedir aclaraciones despues (que gastan mas peticiones).
➤ DeepSeek V4 Flash: Tiene 31,650 peticiones/5h. Es ideal para uso intensivo diario.
➤ Plan Go ($5/mes): Si necesitas mas, el plan Go aumenta significativamente todos los limites.
